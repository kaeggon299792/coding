04 / METHODOLOGY

계산 기준과 유의사항

  1. 2025년 공시 손익계산서의 매출액과 영업이익을 중앙 DB에서 조회합니다.
  2. 현재 매출에는 현행 기금 10%가 이미 차감됐다고 보고, GGR = 현재 매출 ÷ 0.90으로 차감 전 기준을 복원합니다.
  3. {% if scenario.selected_scenario == '1' %}시나리오 1의 변경 후 매출은 GGR × 0.85, 추가 부담은 GGR × 5%입니다.{% else %}시나리오 2의 추가 부담은 MAX(GGR - 3,000억원, 0) × 5%, 변경 후 매출은 현재 매출 - 추가 부담입니다.{% endif %}
  4. 예상 영업이익은 기존 영업이익에서 추가 부담을 차감하고, 예상 영업이익률은 예상 영업이익을 변경 후 매출로 나눕니다.
  5. 세금 효과, 매출 변화, 비용 절감, 법인별 실제 부과 기준은 반영하지 않은 단순 민감도 분석입니다.

Excel 계산식

A2=현재 매출, B2=기존 영업이익, 금액 단위는 억원 기준

GGR: =A2/0.90 {% if scenario.selected_scenario == '1' %} 변경 후 매출: =(A2/0.90)*0.85 추가 기금 부담: =A2-((A2/0.90)*0.85) {% else %} 추가 기금 부담: =MAX((A2/0.90)-3000,0)*(15%-10%) 변경 후 매출: =A2-MAX((A2/0.90)-3000,0)*(15%-10%) {% endif %} 예상 영업이익: =B2-추가기금부담 예상 영업이익률: =예상영업이익/변경후매출

본 화면은 정책 영향 검토를 위한 가상 시나리오이며 확정 법령이나 공식 손익 전망이 아닙니다.
