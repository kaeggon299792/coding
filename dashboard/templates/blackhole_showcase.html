Labs / WebGL Showcase

렌더링 방식 설명

이 페이지는 사이트 콘텐츠와 무관한 별도의 기술 데모입니다. 검색엔진 색인에는 포함되지 않습니다.

무엇을 계산하는가

화면에 보이는 모든 밝은 구조는 강착원반 하나를 휘어진 빛으로 여러 번 겹쳐 본 것입니다.

강착원반과 가스 노이즈

4옥타브 FBM 노이즈를 케플러 회전 좌표계에서 읽어 나선형 필라멘트를 만듭니다. 안쪽 궤도가 바깥보다 훨씬 빠르게 돌며 자연스럽게 전단됩니다.

중력 렌즈와 광자 링

레이마칭 중 광선의 각운동량을 보존하며 궤적을 적분합니다. 광자 구를 스치는 광선은 원반을 여러 번 겹쳐 보여주며, 이것이 그림자 가장자리의 얇은 광자 링이 됩니다.

도플러 편이

원반 안쪽 가스는 광속의 약 0.4배로 공전합니다. 다가오는 쪽은 g³ 상대론적 빔 효과로 더 밝고 푸르게, 멀어지는 쪽은 어둡고 붉게 표현됩니다.

시간 누적과 bloom

카메라가 고정되어 있어 프레임마다 같은 화소를 다시 보므로, 여러 프레임을 누적해 노이즈를 줄입니다. 밝은 영역만 추출해 블러한 뒤 ACES 톤매핑으로 합성합니다.

동작 조건

기기 성능과 접근성 설정에 따라 자동으로 낮은 사양으로 전환됩니다.

  • WebGL2를 우선 사용하고, 지원하지 않는 환경에서는 WebGL1으로 전환합니다. 둘 다 없으면 캔버스를 숨기고 검은 배경과 텍스트만 표시합니다.
  • 소프트웨어 렌더러(가상 데스크톱, GPU 없는 환경 등)를 감지하면 해상도와 스텝 수를 자동으로 낮춥니다.
  • 운영체제에서 "동작 줄이기"를 설정한 경우 애니메이션 없이 정지된 한 장면만 렌더링합니다.
  • 화면 밖으로 스크롤되거나 탭이 비활성화되면 렌더링을 멈춥니다.
